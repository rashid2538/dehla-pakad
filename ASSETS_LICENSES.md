# Asset Licenses

## Sound Effects

All sound effects in `assets/sounds/` are **original works** generated programmatically using ffmpeg synthesis (sine waves + noise generators). They are not derived from any third-party source.

**License:** These assets are part of this project and share its license. No third-party attribution is required.
